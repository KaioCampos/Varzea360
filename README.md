# Várzea360 
> Da escalação ao jogo, do jogo à gestão.

## 📖 Sobre o Projeto
> O Várzea360 é um sistema de gestão para clubes de futebol de várzea. O projeto tem como objetivo auxiliar na organização de clubes, jogadores, comissões técnicas, partidas e competições.

## 🚀 Funcionalidades
> - Cadastro de usuários
> - Cadastro de clubes
> - Cadastro de jogadores
> - Gestão da comissão técnica
> - Escalação de equipes
> - Gerenciamento de partidas
> - Gerenciamento de competições
> - Controle de lesões
> - Controle de despesas

### Objetivo 
> - Centralizar a gestão de clubes de futebol de várzea em uma única plataforma, permitindo o gerenciamento de atletas, comissões técnicas, partidas, campeonatos e demais atividades administrativas.
